# koebun 説明書

**右 ⌥ を押して喋り、もう一度押すと、いま書いていた場所に文字が入る。** それが全部です。
設定は「もっと速く／もっとキレイに／挿入が効かない」のどれかを直すためのもので、最初は何も触らなくて動きます。

---

## 1. 全体の流れ

```
右⌥ ─▶ 録音 ─▶ 音声認識 ─▶ 辞書置換 ─▶ (整形 LLM) ─▶ カーソル位置へ挿入
                  │            │             │
                  │            │             └ 既定 OFF。ON にしたときだけモデルを読む
                  │            └ 「アットマーク」→「@」のような機械置換。必ず同じ結果
                  └ 既定は Apple 音声認識（DL 0）。WhisperKit に替えられる
```

設定画面の3つのタブは、この流れのどこを触るかで分かれています。

| タブ | 触る場所 | ひとことで |
|---|---|---|
| **一般** | 録音 と 挿入 | 音・HUD・ホットキー・挿入方式・履歴 |
| **辞書置換** | 認識のあと | 毎回同じ間違いを機械的に直す |
| **整形** | 挿入の手前 | LLM で文章を整える（使うなら ON にする） |

---

## 2. 最初の3分

1. 起動するとメニューバーにマイクのアイコンが出ます（Dock には出ません）
2. **アクセシビリティ**を許可します。メニューの「アクセシビリティ設定を開く」から koebun を ON
   — これを忘れると右 ⌥ を押しても何も起きません
3. 文字を入れたい場所にカーソルを置く → **右 ⌥** → 喋る → **右 ⌥**
4. 初回だけマイクの許可ダイアログが出るので「許可」

ダウンロードは要りません。数 GB のモデルが要るのは、あとで自分で「WhisperKit」や「整形 ON」を選んだときだけです。

### 状態はアイコンの色で分かる

| アイコン | 状態 |
|---|---|
| マイク（無色） | 待機中。右 ⌥ で録音開始 |
| 赤いマイク | 録音中。右 ⌥ で停止 |
| 青い波形 | 文字起こし・整形中 |
| 緑のチェック | 挿入できた |
| 黄の「!」 | 挿入したが、整形が数値や URL を書き換えた疑いあり（履歴で確認） |
| 橙の警告 | 失敗。メニューを開くと原因が読める |
| 黄の砂時計 | モデル読み込み中（WhisperKit／整形 ON のときだけ） |

### 録音中の HUD

画面下に波形のパネルが出ます。マイクが拾えているかを目で確認でき、ここから停止・キャンセルもできます。
30 秒を超えた録音をキャンセルするときは確認が入ります。

## 3. やりたいこと → どこを触る

設定項目を全部読む必要はありません。困ったことから引いてください。

| やりたいこと | 触る場所 |
|---|---|
| 右 ⌥ 以外のキーで録音したい | 一般 › ホットキー › 「変更」を押して使いたい修飾キー（複数可）を押す。押したまま別のキーを押せば「右⌥ + S」「左⇧ + 左⌘ + 0」のような組み合わせになる |
| ゲームコントローラーやキーマッパーから録音したい | JoyKeyMapper などは修飾キーを**左側**（左⌥ など）として送り、左右の情報を付けないことがある。koebun は左右の情報が無いイベントは左右どちらでも受けるので、設定はそのままでよい。反応しないときは「左⌥ + S」のように左側で録り直す |
| 開始音・停止音を消したい／変えたい | 一般 › サウンド（「なし」も選べる） |
| 録音中のパネルが邪魔 | 一般 › 録音HUD › 表示サイズを「最小」か「非表示」に |
| パネルを画面の上に出したい | 一般 › 録音HUD › 表示位置 |
| 「アットマーク」が「@」にならない | 辞書置換 › 「記号の初期ルールを追加」 |
| 固有名詞がいつも同じ誤変換になる | 辞書置換 › 「ルールを追加」で 読み→正しい表記 を登録 |
| 英数字・URL・メールアドレスの認識が壊れる | 辞書置換で直すか、一般 › 音声認識 を WhisperKit に（約 2.9GB） |
| 句読点や「えーと」を整えて欲しい | 整形 › 「整形 LLM を常駐させる」を ON（初回にモデル DL） |
| Slack はくだけた文、メールは敬体にしたい | 整形 ON にすれば既定で自動。アプリを見てモードが切り替わる |
| 整形で待つのが長い | 整形 › 整形モデルを小さく（4B／8B）、または制限時間を短く |
| 整形で数字や URL が変わって困る | 整形ガードは既定 ON。黄の「!」が出たら履歴で差分を見る |
| ⌘V が効かないアプリ（一部のターミナル等）に入れたい | 一般 › 挿入 › 「キー送出で入力する」を ON |
| 挿入に失敗したときの文章を拾いたい | 履歴（メニュー › 履歴…）→ コピー／再挿入。既定では HUD にも残る |
| 喋った内容を残したくない | 一般 › 履歴 › 保存期間を短く（7日〜無期限） |
| 整形の口調を自分好みに育てたい | 整形 › モード定義 › フォルダを開く → JSON の `systemPrompt` を編集 → 再読み込み |

## 4. 設定項目の一覧

各項目「何をするか／既定／いつ変えるか」を1行ずつ。

### 一般

**サウンド**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 録音開始音 | Glass | 音が要らないなら「なし」。HUD を非表示にしても音で状態が分かる |
| 録音停止音 | Basso | 同上 |

**音声認識**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| エンジン | Apple 音声認識 | 英数字・URL の精度が欲しいとき WhisperKit へ。初回 約 2.9GB、以後は常駐。macOS 26 未満では自動的に WhisperKit |

**録音HUD**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 表示サイズ | 通常 | 「最小」は小さな表示だけ、「非表示」は音だけで状態を知らせる |
| 表示位置 | 画面下部中央 | 下に他の UI があるなら「画面上部中央」 |

**挿入**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| キー送出で入力する | OFF | ⌘V を受け付けないアプリ向け。1文字ずつ送るので長文は遅いがクリップボードを一切触らない |
| 挿入を確認できなかったら結果をクリップボードに残す | ON | OFF にすると常に元のクリップボードへ戻す。文章は HUD と履歴にだけ残る |
| 挿入できなかったとき結果を HUD に残す | ON | パネルからコピー／再挿入できる。OFF でも履歴には残る |

**ホットキー**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 録音トリガー | 右 ⌥ | 「変更」→ 使いたい修飾キーを押す（複数可。右⌥／左⌥／右⌘／左⌘／右⌃／左⌃／右⇧／左⇧／fn。左右は区別）。押したまま別のキー（S や 0 など）を押すと組み合わせ（例: 右⌥ + S、左⇧ + 左⌘ + 0）になり、そのキー入力は前面アプリに届かない。押さずに離すと修飾キーだけ（⇧ を含む・複数の修飾キーは通常キー必須。fn は矢印・F キーと組み合わせ不可）。Esc で中止 |

**履歴**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 保存期間 | 30日 | 7日／30日／90日／1年／無期限。期限切れは自動削除 |
| 保存先 | `~/koebun/history/` | 「フォルダを開く」で中身を見られる。録音・生テキスト・置換後・送信プロンプトが1発話ごとに残る |

### 辞書置換

文字起こしの直後、整形の前に機械的に置換します。LLM を通さないので同じ入力から必ず同じ結果になります。大文字小文字は区別しません。

| 操作 | 内容 |
|---|---|
| ルールを追加 | 「読み（発話される語）」と「置換後」を登録 |
| 記号の初期ルールを追加 | `アットマーク`→`@`、`ドットコム`→`.com`、`スラッシュ`→`/`、`シャープ`→`#`、`アンダースコア`→`_` を足す |

ルールは `~/koebun/replacements.json` に保存されるので、エディタで直接編集しても構いません。
各位置で最も長く一致するルールが1つだけ効き、置換結果が別のルールに連鎖することはありません。

### 整形

**整形**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 整形 LLM を常駐させる | OFF | ON にすると初回にモデルを DL してメモリに常駐。OFF なら整形を飛ばして置換後の文をそのまま挿入 |
| 既定のモード | そのまま | 自動切替に当てはまらないアプリで使うモード。「そのまま」は LLM を通さない最速パス。メニューバーからも切り替えられる |

**モデル**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 整形エンジン | Qwen3（mlx） | Apple Foundation Models は DL 0 だが、数値の書き換えなど禁止事項を破ることがあるので既定にしていない |
| 整形モデル | Qwen3 14B（約 7.8GB） | 速さ優先なら 4B（約 2.2GB）／8B（約 4.5GB）。品質優先なら 32B（約 18GB） |
| 整形の制限時間 | 8秒 | 超えたら整形を諦めて置換後の文を挿入。3〜30秒 |

**コンテキスト**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 整形プロンプトにコンテキストを渡す | ON | 最前面アプリ名・選択テキストなどを LLM に渡す。渡したくなければ OFF（取得自体をしない） |
| アプリ別にモードを自動で切り替える | ON | Slack ならメッセージ、Mail ならメール、のように録音開始時のアプリで決まる。手動でモードを選ぶと次の1回だけそちらが優先 |

**整形ガード**

| 項目 | 既定 | いつ変えるか |
|---|---|---|
| 整形が事実を書き換えていないか点検する | ON | 数値・URL・メールアドレスが整形前後で変わったら黄の「!」で知らせる |
| 固有名詞・識別子まで点検する | OFF | カタカナ・漢字・英数字の連続まで見る。日本語は表記が揺れるので誤検知が増える |

**モード定義**

`~/koebun/modes/*.json`。「フォルダを開く」で編集し、「再読み込み」で反映します。

## 5. 整形モード

整形 ON のときだけ意味を持ちます。既定で5つ入っていて、最前面アプリから自動で選ばれます。

| モード | どう整えるか | 自動で選ばれるアプリ |
|---|---|---|
| そのまま | LLM を通さない | （自動選択なし。既定のモード） |
| メッセージ | やわらかい口語、列挙は箇条書き | Slack・Discord・Telegram・メッセージ |
| メール | です・ます調、段落分け。挨拶や署名は勝手に足さない | Mail・Outlook・Spark・Superhuman |
| コード | 技術用語を一般表記に、識別子はバッククォート、常体 | Terminal・iTerm・Warp・VS Code・Cursor・Xcode・JetBrains・Ghostty・Windsurf |
| メモ | 常体・箇条書き。要約せず、日時・数値・人名はそのまま | Notes・Obsidian・Notion・TextEdit |

### 自分専用に育てる

JSON の主なキー:

| キー | 意味 |
|---|---|
| `systemPrompt` | 整形の方針。ここを書き換えるのが一番効く |
| `appMatch` | このモードに切り替えるアプリ（バンドル ID かアプリ名の部分一致） |
| `context` | LLM に渡す情報。`appName` / `windowTitle` / `selectedText` / `clipboard` / `dateTime` を true/false で |
| `modelId` | このモードだけ別のモデルを使うとき |

履歴の「送信プロンプト」を見ると、実際に LLM へ渡った文面が分かります。プロンプトを直すときの手掛かりにしてください。

## 6. 履歴

メニュー › 履歴…。直前の発話が一番上です。

- **コピー／再挿入** — 挿入に失敗したときはここから拾う
- **録音を再生** — 認識が変だったとき、何と喋ったか聞き直せる
- **整形の差分** — 生テキスト／置換後／整形後を並べて見られる。「!」が出た発話はここで何が変わったか分かる
- **送信プロンプト** — LLM に渡した全文

## 7. 困ったとき

| 症状 | 見るところ |
|---|---|
| 右 ⌥ を押しても何も起きない | アクセシビリティ権限。ビルドし直した後は一度 OFF → ON |
| 録音は始まるが文字が出ない | マイク権限。HUD の波形が動いていなければ拾えていない |
| 文字は出たがカーソル位置に入らない | 挿入先が ⌘V を受け付けていない。「キー送出で入力する」を試す。文章は履歴と HUD に残っている |
| 起動後ずっと黄の砂時計 | モデルの DL 中。整形 OFF・Apple 音声認識に戻せば即座に待機になる |
| 整形が遅い | モデルを小さくする、制限時間を短くする、または整形 OFF で「そのまま」 |
| 挿入後に黄の「!」 | 整形が数値・URL を書き換えた疑い。履歴の差分で確認し、頻発するモードは `systemPrompt` を直す |

## 8. ファイルの場所

すべて端末の中にあります。ネットワークに出るのはモデルの DL だけで、音声もテキストも送信しません。

| 内容 | 場所 |
|---|---|
| 辞書置換ルール | `~/koebun/replacements.json` |
| 整形モード | `~/koebun/modes/*.json` |
| 履歴（録音・テキスト・プロンプト） | `~/koebun/history/` |
| 設定値 | `UserDefaults`（`com.kenta3578.koebun`） |
| WhisperKit モデル | `~/Library/Caches/argmaxinc/whisperkit-coreml/` |
| Qwen3 モデル | `~/Documents/huggingface/models/mlx-community/` |

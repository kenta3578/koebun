## プロダクト目的

開発者本人が、AI への長い指示やメッセージを**手を止めずに口で出す**ための、自分専用・完全ローカルの音声入力。
音声もテキストも端末の外に出さず、毎日の入力を速くすることだけを目的にする。公開（OSS・配布）は、自分が毎日使えるものになった後の副産物であって目的ではない。

## 提供価値

### ターゲットユーザー

開発者本人ひとり。macOS 26 以降。
主戦場は **Claude Code のプロンプト入力（ターミナル）**。次いで Slack・メール・メモ。

### 解決する課題

- AI に長い指示を書くとき、タイピングで思考が途切れ、手が疲れる
- 音声入力を使おうとしても、権限が外れる・誤った失敗警告が出る・挿入されたか分からない、で実用に耐えなかった（2026-09-05 時点で履歴 41 件のうち日常入力はゼロ。挿入成功と確認できた記録もゼロ）
- ターミナルは Accessibility で挿入確認ができないアプリなので、**挿入の確実さと静かさ**がそのまま価値になる

### 価値提案

**認識エンジンでは差をつけていない。** 既定の音声認識は macOS 内蔵の SpeechAnalyzer そのもので、実測 292ms・句読点付き（`engine-benchmark.md`）。WhisperKit large-v3 の 3,906ms に対して 13 倍速く、日本語の平文なら実用上の不足も無い。**認識精度で勝負する余地はもう残っていない**ので、そこは狙わない。

sarari の差は**入り口と出口**、つまり「どう始めて、どこに、どう入れて、どう残すか」にある。

#### 内蔵ディクテーションとの違いは、機能ではなく用途

同じ認識エンジンを使っていても、**設計されている行為が違う**。

- **内蔵ディクテーション = 口述筆記。** 完成した文を口で打つための道具。頭の中で文章を組み立ててから喋る
- **sarari = 考えながら喋るための道具。** 組み立てながら喋り、言い直しとフィラーは後で落とす

実使用で効いている 3 つは、別々の便利機能ではなく**すべてこの 1 点に効いている**:

| 機構 | 効いていること |
|---|---|
| 右⌥トグル録音 | いつ始めていつ終わるかを**自分が**決める（OS のタイミングで切れない） |
| 開始音・停止音 | 画面を見ずに録音状態が分かる。編集中の画面から目を離さない |
| フィラー除去・言い直しの除去 | 「えーと」を気にせず喋れる＝完成した文を用意しなくていい |

これに辞書置換（自分の固有名詞）・クリップボード経由の挿入と復元（**ターミナルに確実に入る**）・履歴が乗る。可変部に記録している 1 日あたりの挿入回数は「正確に文字を打った回数」ではなく、**思考を止めずに Claude Code に投げた回数**である。

#### 残りの 2 点

- **完全ローカル・ゼロダウンロード。** 押せばすぐ入る。クラウドもサブスクも無い
- **邪魔をしない。** 失敗と分かるときだけ警告し、確認できないだけなら黙る。結果は必ず履歴に残る

#### オプションの扱い

**用途が言えないオプションは価値ではなく保守コスト**として扱う。この基準で 2 つを区別する:

- **WhisperKit には残す理由がある。** Apple 音声認識は URL・メール・英数字を**毎回違う壊し方**で崩し（`example.com/invoice` → `Excampe.comインボイス` / `。.comインボイス`）、壊れ方が不定なので辞書置換では救えない。同じ発話で WhisperKit は両方とも完全に正しく取れていた（`engine-benchmark.md` §2）。これは「選べます」ではなく**Apple が崩す入力のための逃げ道**という、名前の付いた用途である
- **LLM 整形は用途が言えなかったので削除した**（#62 の判定、実装は #131）。主戦場が Claude Code である限り不要、というのが実測後の結論

#### 帰結: 薄さが価値

差が「入り口と出口」にある以上、**機能を足すたびに価値が減る**。凍結機能の削除判定（#62）はこの記述を根拠にする。

同じ理由で、**Apple が同等の機能を OS に入れたら sarari を消して終わりでよい**。サブスクも利用者もいないので失うものがない。「公開は自分が毎日使えるものになった後の副産物」という上の判断と整合する。

---

実使用で効いている（残す）: 右⌥トグル録音、Apple 音声認識、辞書置換、クリップボード経由の挿入と復元、履歴、HUD の最小表示、状態アイコン、開始音・停止音、フィラー除去。
実使用で使っていなかったものは **すべて削除済み**（#62 で判定、2026-09-09〜10）: 整形差分ガード（#128）→ アプリ別モード自動切替（#129）→ コンテキスト注入（#130）→ LLM 整形と 5 モード（#131）。**計 2,429 行**。
**WhisperKit だけは残した。** 上記のとおり用途（Apple が崩す URL・メール・英数字の逃げ道）が実測で言えるため。

## 非ゴール

- **Superwhisper を「超える」こと**。比較で勝つことは目的ではない。自分の入力が速くなれば十分
- 会議モード・話者分離・ファイル文字起こし
- iOS / Windows・多言語（英語含む）・クラウドモデル・チーム機能
- Homebrew などでの配布・署名済みバイナリ公開。**自分が 1 か月使い続けた後に再検討**する保留事項であり、いまは非ゴール
